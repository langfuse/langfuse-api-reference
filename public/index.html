Langfuse API reference

The interactive reference on this page needs JavaScript. The full API is described by the OpenAPI spec: https://cloud.langfuse.com/generated/api/openapi.yml. Self-hosted deployments serve it at /api/openapi.yaml.

Authentication

HTTP Basic auth with the project's public key as username and secret key as password. Base URLs: https://cloud.langfuse.com (EU), https://us.cloud.langfuse.com (US), https://jp.cloud.langfuse.com (JP), https://hipaa.cloud.langfuse.com (HIPAA), or your self-hosted URL.

Current endpoints for reading data

  • Traces, spans and generations: GET /api/public/v2/observations
  • Scores: GET /api/public/v3/scores
  • Aggregated metrics (cost, latency, counts): GET /api/public/v2/metrics
  • Prompts: GET /api/public/v2/prompts
  • Datasets: GET /api/public/v2/datasets
  • Ingest traces: POST /api/public/otel/v1/traces (OpenTelemetry)

Deprecated, removed on Langfuse Cloud on November 16, 2026: GET /api/public/traces, GET /api/public/observations, GET /api/public/sessions, GET /api/public/scores, GET /api/public/v2/scores, GET /api/public/metrics. See the migration guide.

From a terminal or coding agent

The Langfuse CLI wraps every endpoint: npx @langfuse/cli api <resource> <action>. See the CLI docs and the public API docs.
